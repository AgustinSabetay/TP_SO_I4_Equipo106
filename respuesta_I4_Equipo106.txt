G- ¿Qué soluciones pueden aplicar y cual seria la consecuencia de cada solución

G- Las soluciones posibles son:
-Utilizar "git pull" para descargar e integrar los cambios remotos mediante un merge. Esto permite conservar los cambios de ambos integrantes, 
aunque puede generar conflictos que deben resolverse manualmente.
- Utilizar "git pull --rebase" para colocar los commits locales después de los cambios remotos. Permite mantener un historial más lineal, 
pero también pueden aparecer conflictos que deben resolverse.
- Resolver los conflictos manualmente, conservando los cambios de todos los integrantes, y luego realizar el commit correspondiente y volver a intentar el push.

En nuestro caso, utilizamos "git pull --no-rebase origin TESTING" para integrar los cambios de ALFA con los de BETA. 
Git abrió Visual Studio Code para confirmar el mensaje del merge. Después de finalizar la integración, el directorio de trabajo quedó limpio y 
pudimos realizar el push correctamente.
